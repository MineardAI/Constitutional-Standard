# Security Policy

## Scope

This policy covers the Constitutional Standard repository and its public Reference Foundation implementation.

The project is a bounded, non-sovereign, non-executing reference implementation. It is not a production runtime, deployment system, transport layer, persistence layer, or operational authority.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately by emailing:

`tyrone@ulantra.com`

Do not disclose exploitable details in a public issue, pull request, discussion, or other public channel. Include enough information to reproduce the issue, the affected file or crate, the potential impact, and any suggested mitigation.

If the report concerns sensitive material, do not include secrets or personal data in the initial message. Describe the material and request a secure follow-up channel instead.

## Response

Reports will be reviewed by the project maintainer. Valid reports will be assessed for impact, reproducibility, affected versions, and an appropriate remediation or disclosure timeline.

## Supported versions

The current public implementation version is `reference-foundation-0.15.0`. Security reports involving other versions are still welcome, but remediation priority may depend on reproducibility against the current public implementation.
