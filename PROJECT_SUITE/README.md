# Constitutional Standard Project Suite

This Project Suite is a derivative operating context for Portfolio and project maintenance. It does not replace the canonical constitutional documents or the implementation workspace.

## Authority

Canonical project material remains at the repository root and under `implementation/`. The suite summarizes and indexes that material; it does not grant authority, adoption, certification, production authorization, or implementation permission.
