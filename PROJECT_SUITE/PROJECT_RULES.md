# Project Rules

- Preserve the distinction between canonical constitutional source, implementation evidence, and derivative summaries.
- Preserve non-sovereign, non-executing, fail-closed, deterministic boundaries.
- Do not infer adoption, authority, conformance, certification, production readiness, or operational recognition from implementation or passing tests.
- Preserve source/version/scope discrepancies as findings; do not silently normalize them.
- Update this suite only from verified canonical project material.
- Do not reverse-sync Portfolio summaries into canonical project files.
- Keep the Source Pack bounded to 40 files or fewer and record its provenance.
