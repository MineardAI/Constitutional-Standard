# Constitutional Standard / architecture-api

Derivative summary. Canonical sources: `../../README.md`, `../../implementation/docs/IMPLEMENTATION_SCOPE.md`, and `../../implementation/docs/COMPONENT_CATALOG.md`.

The reference foundation is a typed, deterministic, non-sovereign Rust implementation. Its bounded domains include source/context resolution, authority, identity and participation, artifacts and provenance, state and transitions, interaction boundaries, canonical representation, traceability, verification, evidence, release continuity, and activation/operational-recognition records.

The implementation exposes inspectable records and validation boundaries. It does not provide a universal wire protocol, execution runtime, transport, persistence, deployment, or constitutional interpretation.
