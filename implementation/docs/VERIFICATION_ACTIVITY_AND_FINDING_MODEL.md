# Verification Activity and Finding Model

Verification requirements bind a subject, source, implementation version, and statement. Criteria bind requirements to explicit statements and limitations. Plans bind requirements, criteria, activities, context, scope, and limitations. Activities bind a plan, requirement, criterion, subject, explicit method, context, inputs, evidence references, traceability, canonical representation, and observation identifiers.

Observations are produced records, not findings. Findings require an observation basis and declare severity, disposition, polarity, subject, and detail. The validator detects unresolved blocking/invalidating findings, contradictory positive/negative findings, unknown subjects, missing inputs, missing criteria, malformed bindings, and implementation-version mismatches.

Supported bounded methods include structural/schema validation, canonical round-trip, deterministic output, source/version binding, traceability, positive/negative/boundary/invariant testing, compatibility checking, manual review, governed-record review, and documentation review.
