# Evidence Object and Subject Model

`EvidenceObject` is distinct from `EvidenceReference`, `EvidenceRecord`, potential material, and package membership. Every object has a stable object identifier, typed subject, kind, content reference, claim, relevance statement, version, and explicit limitations.

Subjects cover constitutional source bindings, requirements, components, artifacts, versions, traceability, verification records, assurance bases, gates, deviations, compatibility, and bounded future release/activation-readiness references. Subject typing does not grant authority.
