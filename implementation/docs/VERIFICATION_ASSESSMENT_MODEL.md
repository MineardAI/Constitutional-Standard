# Verification Assessment Model

An assessment explicitly identifies activities, finding identifiers, scope, outcome, basis, limitations, and canonical representation binding. It is not an observation, finding, assurance, evidence object, conformance determination, or certification decision.

Outcomes preserve `Satisfied`, `NotSatisfied`, `PartiallySatisfied`, `Indeterminate`, `NotApplicable`, `InvalidVerificationRequest`, `Incomplete`, `Conflicted`, `Verified`, `VerifiedWithConditions`, `NotVerified`, `Inconclusive`, and `Invalid`.

Assessment validation requires a resolved activity basis, a non-empty finding basis, an explicit assessment basis, deterministic ordering, and compatible implementation/source context. Assessment results remain scope-bound and do not infer correctness from canonical decoding, traceability completeness, or test count.
